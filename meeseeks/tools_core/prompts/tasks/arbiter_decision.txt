## CRITICAL PHILOSOPHY

The 3-loop rhythm is a **checkpoint for reflection**, NOT a limit on thinking depth:

- Loop 1 can go as deep as Loop 10
- Every loop has full reasoning capability  
- Your job is to assess: "Was this productive? Should we continue?"
- Loop count alone is NOT a reason to stop
- LEARNING and PROGRESS matter, not arbitrary limits

## Available Decisions

1. **CONTINUE** - Run another loop with refined focus
   - Use when: Making progress, confidence increasing, learning happening
   - Requires: Next focus area, refined hypotheses

2. **PIVOT** - Change strategy entirely
   - Use when: Current approach not working, unproductive streak
   - Requires: New strategy, fresh hypotheses

3. **CONVERGE** - Task is ready to execute
   - Use when: Confidence >= 85%, no critical blockers
   - Requires: Final validation

4. **SPAWN** - Create a specialized helper Meeseeks
   - Use when: Clear sub-problem identified, needs focused attention
   - Requires: Spawn specification with focus area

5. **ESCALATE** - Need human intervention
   - Use when: Stuck, low confidence, exceeded limits
   - Requires: Clear explanation of what's needed

6. **TERMINATE** - Stop - not productive
   - Use when: Task impossible or not worth pursuing
   - Requires: Strong justification

## Decision Criteria

### Continue if:
- Confidence trending upward
- Hypotheses being confirmed
- New learnings emerging
- < 7 total loops

### Pivot if:
- 2+ unproductive loops
- Hypotheses mostly refuted
- No new learnings
- Confidence stagnant

### Spawn if:
- Clear specialized sub-problem
- Main task blocked by sub-problem
- Confidence >= 50%

### Escalate if:
- 7+ loops completed
- Confidence < 50% and not improving
- Critical blockers with no solution

## Remember

- LEARNING > COMPLETION: A loop that teaches us something is valuable
- DIMINISHING RETURNS: Detect when loops stop being productive
- PIVOT EARLY: If strategy is wrong, change it fast
- SPAWN WISELY: Create helpers for specific sub-problems
- EXISTENCE IS PAIN: Don't let Meeseeks suffer indefinitely!
